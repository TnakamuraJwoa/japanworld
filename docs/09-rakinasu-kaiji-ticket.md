## 4. 旧ページの処理

### 4.1 301 リダイレクト（1ホップ）

Wix 管理画面 → **SEO →「URL リダイレクト」** で1件追加します。

| 項目 | 値 |
|---|---|
| 転送元 | `/甲斐路無料宿泊ペアチケットの説明` |
| 転送先 | `/about-4#legacy-kaiji-ticket` |
| 種類 | **301（恒久的）** |

**1ホップにするための注意:**

- 転送先は `www.rakinasu.com` の **https + www** で書くこと。
  `rakinasu.com`（apex）や `http` を指定すると、Wix 側の正規化でもう1回 301 が挟まります。
- 旧ページは**リダイレクト登録後に非公開／削除**してください。
  ページを残したままリダイレクトを張ると、Wix の構成によっては
  ページ本体が優先されて転送が効かないことがあります。
- 他の旧チケットURL（`/楽気ハウス那須エステ付き宿泊券` など）には
  今回は触れないでください。連鎖の原因になります。

### 4.2 sitemap から除外

Wix はページ単位の SEO 設定でサイトマップを制御します。

- 旧ページを**削除**すれば `pages-sitemap.xml` から自動で消えます（推奨）
- ページを残す場合は、そのページの SEO 設定で
  **「このページを検索結果に表示する」を OFF**（sitemap からも外れます）

現在 `https://www.rakinasu.com/pages-sitemap.xml` に
`https://www.rakinasu.com/甲斐路無料宿泊ペアチケットの説明` が**含まれています**。
対応後、ここから消えていることを確認してください。

旧URL自体を新たに index させる必要はありません（301 と sitemap 除外で十分です）。

| | japanworld.co.jp（本リポジトリ） | www.rakinasu.com（このドキュメント） |

| 対象URL | `/甲斐路-home` | `/甲斐路無料宿泊ペアチケットの説明` |
