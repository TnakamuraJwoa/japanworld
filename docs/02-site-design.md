# 02. 現行サイトの問題点と、新サイトの設計

---

## 1. いちばん大きな問題 — サイトの役割が定義されていない

調査の結果、Japan World株式会社は 4 つの Web 資産を持っています。

| サイト | 実際の役割 | 現状 |
|---|---|---|
| **www.japanworld.co.jp** | ？ | 会社概要 + 会員権 + **ホテルの施設紹介一式**（rakinasu.com と重複） |
| **www.rakinasu.com** | 楽気ハウス那須 ホテル公式サイト（施設情報・季節の特集・宿泊税のお知らせ） | 宿泊予約・季節の特集・宿泊税の告知など**最新情報はこちらにある** |
| **jwcc.japanworld.co.jp** | JWCCS 会員専用予約システム | ログイン必須のアプリ |
| **nft.japanworld.co.jp** | JW NFT Platform | ⚠ TLS証明書失効中 |

japanworld.co.jp は **rakinasu.com の古いコピーを抱えたまま、コーポレートサイトでもホテルサイトでもない状態**になっています。
その結果、

- 同じ「楽気ハウス那須」の情報が 2 つのドメインにあり、片方が古い（客室数・開業年・アクセス・サロン構成が食い違う）
- 検索エンジンから見ても、どちらが正典か判断しづらい
- 一般のお客様がこのサイトに来ても、**予約ができない**（rakinasu.com へのリンクがトップに 1 本あるだけ）

### → 新サイトの役割定義

**japanworld.co.jp = Japan World株式会社のコーポレートサイト兼、楽気ハウスのブランドハブ**

- 楽気ハウス那須が「どんな施設か」は自社サイトとして責任を持って掲載する（旧URLの資産も守る）
- ただし **在庫・料金・最新のお知らせは rakinasu.com が正典**と位置づけ、明示的に送客する
- 会員権と会社情報は japanworld.co.jp が正典
- 予約は「一般 / 会員」の経路として明示する
  （NFT の経路は証明書失効のため現在非表示。§5 参照）

## 3. 新サイトのサイトマップ

ページ数は現行と同じ 12（×4言語）に保ちつつ、中身を入れ替えています。

```
/                          トップ
├─ /raki-house/            楽気ハウス那須（施設総覧＋ロビー＋おもてなし）
│   ├─ /rooms/             客室
│   ├─ /spa/               温泉・大浴場・露天風呂
│   ├─ /dining/            レストラン & バー
│   ├─ /banquet/           コンベンションホール
│   ├─ /salon/             スパ&サロン（細胞浴SALON 太古の甕 ／ Esthetic Salon RICHIA）
│   └─ /nasu/              那須高原と周辺観光
├─ /booking/               宿泊予約のご案内      ★新設
├─ /membership/            楽気ハウス会員権
├─ /access/                アクセス              ★新設
└─ /company/               会社概要
```

同じ構成を `/en/` `/zh/` `/vi/` にも用意（合計48ページ）。

### 何を減らし、何を増やしたか

| 現行 | 新 | 理由 |
|---|---|---|
| `/rakihouse` と `/楽気ハウス-那須` の2ページ | `/raki-house/` 1ページ | 同一タイトル・同一descriptionの重複ページだった |
| `/lobby`（単独ページ） | `/raki-house/` 内の一節 | 内容が4段落と少なく、施設総覧の一部として読ませたほうが自然 |
| `/about`（取り組み＋アクセス） | 取り組み → `/raki-house/` ／ アクセス → `/access/` | 性質の違う2つが1ページに同居していた |
| （なし） | `/booking/` ★ | ご予約窓口（一般／会員）を明示する専用ページ |
| （なし） | `/access/` ★ | 住所・車・電車・バス・送迎バス・駐車場・地図を独立ページに |
| （なし） | `/raki-house/nasu/` | 那須高原の解説と周辺観光。`/楽気ハウス-那須` にあった内容を活かす |

## 5. 宿泊予約導線の設計

トップと `/booking/` に、同じカードを置きます。

| | 一般のお客様 | 楽気ハウス会員の方 |
|---|---|---|
| 強調 | **主 CTA（塗り・影付き）** | 副 |
| ボタン | 宿泊予約サイトで予約 → **www7.489pro.com（予約エンジン）** | JWCCS にログイン → jwcc.japanworld.co.jp |
| 補助 | TEL 0287-74-6740（受付 9:00〜18:00） | 会員権ページへのリンク |

- 「会員制ホテルだが一般客も泊まれる」ことを本文で明示（rakinasu.com の宿泊約款第1条に基づく）

### 外部の2つの遷移先の使い分け（2026-09-11 変更）

一般のお客様向けの遷移先を、ホテルサイト経由から**予約エンジンへの直接遷移**に変更しました。

| 用途 | 遷移先 | 使っている箇所 |
|---|---|---|
| **「予約する」CTA** | `www7.489pro.com/asp/489/menu.asp?id=09420002&lan=JPN`<br>（Resort Hotel 楽気ハウス那須 プラン一覧画面） | 予約導線カード「一般のお客様」／ページ下部のCTA帯／`/raki-house/` の宿泊プラン案内／`/raki-house/rooms/` の料金注記　計60リンク（4言語 × 15ページ） |
| **サイト名で示すリンク** | `www.rakinasu.com` | フッター「関連サイト」／`/company/` の関連サイトカード／`/booking/` 下部の補助ボタン　計57リンク |

動詞（予約する）で誘うボタンは予約エンジンへ、サイト名で示すリンクはホテルサイトへ、という切り分けです。
`src/data/site.ts` の `EXTERNAL.booking` と `EXTERNAL.hotelSite` が出典です。

遷移先が2つになったため、呼び方を次のとおり整理しました。

| 呼び方 | 実体 |
|---|---|
| 宿泊予約サイト / booking site / 住宿預約網站 / trang đặt phòng | **www7.489pro.com**（予約エンジン） |
| ホテル公式サイト / official site / 官方網站 / trang chính thức | **www.rakinasu.com** |

表示言語は `bookingUrl(lang)` で出し分けています。
英語ページのみ `lan=ENG`（Package list）、日本語・中国語・ベトナム語は `lan=JPN`。
`lan=CHN` は日本語表示に戻るため使っていません。

### NFT宿泊券の導線について（現在は非表示）

当初は「NFT宿泊券をお持ちの方」を加えた 3 カード構成でしたが、
**nft.japanworld.co.jp の TLS 証明書が失効している**ため、
2026-09-11 の公開前修正で**全ページから NFT 導線を外し、2 カード構成に再配置**しました。

- カードが 2 枚のときは `.routes--pair`（最大幅 58rem・中央寄せ）が当たり、
  3 枚分の幅に引き伸ばされないようにしています
- 出し分けは `src/data/site.ts` の `FEATURES.nftLink`。`true` に戻せば 3 カード構成に復旧します
- 文言は 4 言語ぶんすべて残してあります

詳細と復旧手順は docs/04-content-review.md の要確認 #6 を参照してください。

### 「公式サイト」という語について

rakinasu.com へのリンクラベルは、当初「楽気ハウス那須 公式サイト」としていましたが、
japanworld.co.jp 側も楽気ハウス那須の情報を掲載しているため
**どちらが「公式」なのか紛らわしい**という判断で、
2026-09-11 の公開前修正で **「楽気ハウス那須 宿泊予約サイト」** に統一しました。

| 箇所 | 現在のラベル（日本語） |
|---|---|
| フッター「関連サイト」 | 楽気ハウス那須 **ホテル公式サイト** → rakinasu.com |
| 予約カード・CTA帯の主ボタン | **宿泊予約サイトで予約** → www7.489pro.com |
| 会社概要「関連サイト」カード | 楽気ハウス那須 **ホテル公式サイト** → rakinasu.com |

あわせてフッターの関連サイト欄に
**「当サイトは Japan World株式会社のサイトです。以下は別サイトへ移動します。」**
という一文を入れ、運営会社サイトと宿泊予約サイトの役割が混同されないようにしています
（英・中・越も同趣旨の文言）。

なお「那須町公式サイト」は那須町の公式サイトそのものなので、この語のまま残しています。

## 6. デザインの方向性

現行 Wix サイトのレイアウトは再現していません。

| 要素 | 決め方 |
|---|---|
| **主色：藍（#0a4f79 系）** | 施設の実物に由来。楽気ハウスの円形ロゴが藍色、大浴場の壁が藍染、浴場の暖簾も藍 |
| **地色：生成りの紙色（#fbf9f5）** | 和の設えに合う暖色系オフホワイト |
| **アクセント：金（#a8842c）** | JWロゴの黄色を、印刷物向けに落ち着かせた色。見出しの罫と小見出しにのみ使用 |
| **見出し：明朝体** | Hiragino Mincho ProN / Yu Mincho など OS 標準。Webフォントは読み込まない |
| **本文：ゴシック体** | 同上。行間 1.85、`font-feature-settings: 'palt'` で日本語の詰めを調整 |
| **写真主役** | 全画面ヒーロー + 大きめの図版。装飾は罫線1本と余白で構成 |
| **アニメーション** | なし（`prefers-reduced-motion` にも対応） |
| **JavaScript** | モバイルメニューの開閉のみ。**ビルド後の JS は 0 バイト**（インライン1ブロック） |

ヒーロー写真には、縦グラデーションに加えて**左からの暗がり**を重ねています。写真全体を暗くせずに文字だけ読みやすくするためです。

### 周辺観光の写真について

以前は「那須の風景写真」を各スポットのカードに割り当てていたため、
**写真と施設名が一致していませんでした**（例：殺生石のカードにロープウェイの写真）。

### 画像処理

- 元画像は `assets/source/`（参考サイト由来のものは `rk-` 接頭辞）
- `npm run images` で WebP の複数幅を生成し、`src/data/images.generated.ts` に
  幅・高さ・alt を書き出す（`width`/`height` を必ず出力するため CLS が出ない）
- 現在 100点 / 配信用 合計 26.5MB（元画像 111.3MB）

## 7. アクセシビリティ

- 本文へスキップリンク
- ランドマーク（header / nav / main / footer）と `aria-current`
- タップ領域は最小 44×44px
- フォーカスリング（3px・オフセット2px）
- 装飾目的の画像は `alt=""`、内容のある画像は日本語の alt
- ヘッダーの開閉ボタンは `aria-expanded` / `aria-controls`、Esc で閉じる
- 電話番号は `tel:` リンク（`format-detection: telephone=no` で誤検出は抑止）
- 外部リンクは `↗` 記号 + `rel="noopener"`
