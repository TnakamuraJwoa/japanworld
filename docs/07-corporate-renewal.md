| `/business/wellness/`・`/beauty/` | サロン自体の詳細ページ。取り違えが起きないよう、**事業概要の冒頭・本文・meta description で運営会社を明記** |
| `/company/` 事業内容 | 「当社が運営している事業」と「楽気ハウス那須の館内施設」に見出しを分け、後者に運営会社を注記 |

```
src/data/site.ts            OPERATORS … 会社名の定義（japanworld / jworld）
src/data/business.ts        Business.operator … 事業ごとに運営会社を必須指定
                            OWN_BUSINESSES … 当社の事業（トップと /business/ の主役）
                            INHOUSE_SALONS … 館内施設として扱うサロン
src/components/Footer.astro フッターの運営会社表示
```

`Business.operator` は**省略可にしていません**。事業を追加するときは必ず運営会社を指定します。
`OWN_BUSINESSES` / `INHOUSE_SALONS` は `operator` から自動で振り分けられるので、
新しい事業を足しても「当社の事業として並べてしまう」事故は起きません。

#### SEO 上の扱い

- **meta description** … トップと `/business/` は楽気ハウス那須を主語にした文。
  `/business/wellness/`・`/beauty/` は「JWORLD CO.,LTD が運営する」で始める。
- **OGP 画像** … トップと `/business/` はホテルの画像（サロン画像を使わない）。
- **JSON-LD** … サロンに対する `LocalBusiness` 等の事業体マークアップは**出力していない**。
  `Organization`（Japan World）はページの発行者としてのみ使用し、`knowsAbout` は削除済み。
  `LodgingBusiness` は楽気ハウス那須にのみ付与。
- **breadcrumbs** … サイト内の階層を示すだけで、事業の帰属は主張していない。

#### 構造化データ

`Organization`（Japan World株式会社）から `knowsAbout`（登記上の事業内容10項目）を**削除**しました。
サロン運営を当社が行っていると読まれる余地をなくすためです。
`LodgingBusiness` は楽気ハウス那須（Japan World株式会社の事業）のみで、
サロンに関する主張は含みません。

## 7. お知らせと microCMS

`src/data/news.ts` は **microCMS のリスト形式レスポンス `{ contents, totalCount, offset, limit }`
と同じ形**にしてあります。将来 microCMS へ接続するときは、このファイルの中身を fetch に
差し替えるだけで、`src/pages/news/*` は 1 行も変更せずに済みます。

```ts
const res = await fetch(`${BASE}/news?limit=${limit}&offset=${offset}`, {
  headers: { 'X-MICROCMS-API-KEY': import.meta.env.MICROCMS_API_KEY },
});
return await res.json();   // ← getNews() と同じ形
```

⚠ 本番の microCMS へは接続していません。

### 7.1 microCMS 化の優先順位（提案）

| 対象 | 優先度 | 理由 |
|---|---|---|
| お知らせ | ★★★ 必須 | 更新頻度が最も高い。`news` API（日付・タイトル・カテゴリ・本文・公開状態） |
| 事業カードの説明文・画像 | ★★ | 事業の入れ替えが起きうる。`business` API |
| 会社概要の値（資本金・所在地・代表） | ★ | 変更頻度は低いが、誤りを自分で直せる利点 |
| 理念・固定文言 | ✕ 不要 | コード管理で十分 |

### 7.2 現在のお知らせ

**1件のみ**です（那須町宿泊税）。出典が確認できたものだけを登録しており、
件数合わせのサンプル記事は作っていません。

一覧は10件ごとにページ送りされ、11件目から `/news/page/2/` が自動生成されます。
100件でも構造上の問題はありません。

→ **★ 要対応**: 掲載したいお知らせをご指示ください。`src/data/news.ts` に追記します。
